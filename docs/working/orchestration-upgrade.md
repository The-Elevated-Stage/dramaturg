Work as teams teammate(inter-session communication instead of AskUser). This is meant for when a CEO/PM/TL launches a teammate(Agent Teams Teammate Agent, NOT simple task agent) and the teammate launches this skill, it needs to move to full-LLM-mode where the use role is replaced with the team-leader LLM. All communication needs to run through the Teams send_message system. This mode must force the html-review doc setting to FALSE for that run(team-lead LLM does not need the HTML doc). In this mode, the per-phase review is still condensed to a single-file review(like with HTML-mode) and the entire markdown file is pointed to for the team-lead's review. The REASON for this single-file review is that the per-phase approach was for easier human reading. The LLM can faithfully read the entire file as it needs in one go. The communication pattern for these full-LLM sessions is to write anything >~300 chars to a file and then send_message with @ file pointer. send_message can be fragile with large or heavily-formatted messages and the file-pointer is much more durable. This approach has been tested and has worked fairly well, but the communication channel change drifted after a while, we need to help reinforce this. Session's launched in this full-LLM mode will be instructed of that in the launch prompt, "You are a teammate in full-LLM mode" or "You are spawned as an agent teammate, use send_message for communication", something along these lines.

- Bootstrap should support capturing this intent from the intial prompt and should set some persistent, frequently-referenced, flag that tells the session to NOT prompt the user AT ALL(They will NOT respond, this is meant for sessions that will be running in the background and not user-facing).
- Any phases are structured as a 1-at-a-time presentation COULD be condensed into single-file-presented phases with a little more back-and-forth discussion maybe. Again, LLM's can parse all N questions and provide feedback easier than a person can parse all N questions and properly provide answers. Also much quicker, while a person may take ~20+ minutes to read ~6 detailed questions, think about the answers, and provide answers, the LLM can handle this task in a sweep.
